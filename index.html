GARRY'S MOD 9

Retro GMod 9 Deneyimi

Garry's Mod'un efsanevi 9.0.4 sürümünü Steam'e ihtiyaç duymadan (veya Steam üzerinden manuel kısayol ile) çalıştırmak isteyenler için hazırladığım rehber sayfasına hoş geldiniz.

[ GMOD 9 SCREENSHOT ]

Aşağıdaki butona basarak kurulum dosyalarını indirebilir ve rehberi takip edebilirsiniz.

Kurulum ve İndirme

↓ GMOD 9 DOSYALARINI İNDİR
⚠️ ÖNEMLİ: İndirme tamamlandıktan sonra aşağıdaki talimatları eksiksiz uygulayın!

1. steam_appid Dosyası

Zip içindeki steam_appid.txt dosyasını kopyalayın ve şu klasörün içine (hl2.exe'nin yanına) yapıştırın:

C:\Program Files (x86)\Steam\steamapps\common\Source SDK Base\

2. Kısayol (Shortcut) Ayarları

ADIM 1: Source SDK Base içindeki hl2.exe'ye sağ tıklayıp "Kısayol Oluştur" deyin.
ADIM 2: Kısayola sağ tıklayıp "Özellikler" seçeneğine girin.
ADIM 3: Hedef ve Başlama Yeri kısımlarını aşağıdaki gibi düzenleyin.

Hedef (Target):

"C:\Program Files (x86)\Steam\steamapps\common\Source SDK Base\hl2.exe" -game "C:\Program Files (x86)\Steam\steamapps\sourcemods\gmod9\"

Başlama Yeri (Start-in):

"C:\Program Files (x86)\Steam\steamapps\common\Source SDK Base"

NOT: Başlatma yerine elleme yapmanız önerilmez, ancak yukarıdaki yolun doğruluğundan emin olun. Yanlış dizin crash hatasına sebep olur.

Sıkça Karşılaşılan Hatalar

Extra App ID set to 320: steam_appid.txt dosyasının Source SDK Base klasöründe olduğundan emin olun.

Mounting hatası: sourcemods klasörünün adını ve içindeki gmod9 klasörünü kontrol edin.
