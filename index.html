GARRY'S MOD 9

Retro GMod 9 Deneyimi

Garry's Mod'un efsanevi 9.0.4 sürümünü Steam'e ihtiyaç duymadan (veya Steam üzerinden manuel kısayol ile) çalıştırmak isteyenler için hazırladığım rehber sayfasına hoş geldiniz.

[ GMOD 9 SCREENSHOT ]

2006-2009 yıllarının efsane modunu Source SDK Base 2006 altyapısıyla hayata döndürüyoruz. Yan menüden kurulum adımlarına geçebilirsin.

Kısayol (Shortcut) Kurulumu

GMod 9'u doğru çalıştırmak için "Hedef" (Target) yolunu elle düzenlememiz gerekiyor. İşte adım adım yapman gerekenler:

ADIM 1: Source SDK Base 2006'nın kurulu olduğundan emin olun.
ADIM 2: C:\Program Files (x86)\Steam\steamapps\common\Source SDK Base klasöründeki hl2.exe dosyasına sağ tıklayıp kısayol oluştura tıklayın.
ADIM 3: "Öğenin konumunu yazın" kısmına Source SDK Base içindeki hl2.exe yolunu ve oyun parametresini ekleyin.

Hedef (Target) Şöyle Olmalı:

"C:\Program Files (x86)\Steam\steamapps\common\Source SDK Base\hl2.exe" -game "C:\Program Files (x86)\Steam\steamapps\sourcemods\gmod9\"

Başlama Yeri (Start-in) ise Böyle OLmalı

"C:\Program Files (x86)\Steam\steamapps\common\Source SDK Base"

NOT: "Başlatma Yeri" (Start In) kısmına dokunmayın! Orayı hl2.exe'nin bulunduğu klasör olarak otomatik bırakacaktır, elleme yaparsak oyun crash verebilir.

Sıkça Karşılaşılan Hatalar

Mounting hatası alıyorum: sourcemods klasörünün adının küçük harf olduğundan ve gmod9 klasörünün tam orada olduğundan emin olun.

Steam is not running: GMod 9 eski olduğu için arkada Steam'in açık olması gerekebilir, ancak kısayol yöntemi genelde bunu bypass eder.
